CarCare Mobile App

A simple Android application for managing car maintenance, service logs, and vehicle information. Built to practice Android development using Kotlin, Gradle Kotlin DSL, and modern app structure.

Features

Add and manage vehicles

Track maintenance tasks (oil change, tire rotation, inspections, etc.)

View service history

Simple and clean UI

Tech Stack

Language: Kotlin

Platform: Android

Build System: Gradle (Kotlin DSL)

Tools: Android Studio, GitHub

Project Structure
mobile_appCarCare/
│
├── app/                  # Android app module (source code, layouts)
├── gradle/wrapper/       # Gradle wrapper files
├── build.gradle.kts      # Project build configuration
├── settings.gradle.kts   # Modules included
└── .gitignore

Running the Project

Clone the repo:

git clone https://github.com/lamija84/mobile_appCarCare.git

Open in Android Studio

Let Gradle sync

Run on emulator or Android device
